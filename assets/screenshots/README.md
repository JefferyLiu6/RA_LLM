# Screenshot Assets

Current README presentation assets are the SVG files in this folder:

- `project_results.svg`
- `dataset_pipeline.svg`
- `dpo_pipeline.svg`
- `output_example.svg`

Regenerate them after rerunning evaluations with:

```bash
make readme-assets
```

The PNG files are legacy rank-sweep/dashboard screenshots kept for historical context and are not used by the current README.
